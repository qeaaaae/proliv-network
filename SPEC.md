# SPEC: Собственный VPN-сервис (Remnawave + TG-бот + Mini App)

> Статус: черновик требований. Дата: 2026-10-25.
> Бренд (рабочее название): **Proliv Network**. Домен: proliv.net (свободен по RDAP на 25.10.2026, ~$11-13/год; бюджет домена до 300 ₽ - рассматривать proliv.xyz/.site как дешёвую альтернативу, .ru не брать - риск делегирования РКН).
> Референс UX/продукта: ranteis.eu (TG-бот + мини-апп с ЛК, рефералка, баллы).

---

## 1. Цель

Запустить собственный коммерческий VPN-сервис:

- 2 VPN-локации: **Эстония** и **Великобритания**
- Управление: **Remnawave** (панель + ноды, документация docs.rw)
- Продажи: **Telegram-бот** + **Telegram Mini App** (личный кабинет под собственным брендом)
- Маскировка/раздача трафика: **CDN Яндекс Облако** для VPN-трафика
- Тариф: **179 ₽/мес**, 5 устройств, 1 ТБ трафика; докупка трафика и устройств за деньги

## 2. Принятые решения (ответы на открытые вопросы)

## 3. Архитектура

```
[Юзер в TG-боте]
    |
    v
[TG-бот (remnawave-tg-shop или свой)] --API--> [Remnawave Panel]
    |                                               |
    v                                               v
[Mini App ЛК (webapp)] <----> [Subscription page]   |
                                                    | подключение нод по ключам
                                    +---------------+---------------+
                                    |                               |
                            [Node EE (VPS)]                 [Node UK (VPS)]
                                    |                               |
                          [YC CDN: ee-cdn.dom]            [YC CDN: uk-cdn.dom]
                                    |                               |
                              юзеры подключаются через CDN-домены
```

### Компоненты

1. **VPS x2**: EE + UK. Минимум: 1 vCPU / 1-2 GB RAM / 20 GB SSD / >=10-20 TB трафика или безлимит.
2. **Remnawave panel**: на отдельном дешёвом VPS или на одной из нод. Домен `panel.<domain>` (HTTPS, Let's Encrypt).
3. **Remnawave nodes**: на каждом VPS, привязка к панели по секретному ключу.
4. **Subscription page**: `sub.<domain>` - отдаёт юзеру ссылку-подписку и конфиги.
5. **Домен**: один, поддомены под всё (`panel`, `sub`, `cdn-ee`, `cdn-uk`).
6. **TG-бот**: продажи, тарифы, рефералка, баланс, уведомления.
7. **Mini App**: ЛК - трафик, устройства (HWID-лимит 5), кнопка подключения, докупка.
8. **Yandex Cloud CDN**: CDN-ресурс поверх каждой ноды для проксирования/маскировки VPN-трафика.
9. **TG-прокси** (веб-прокси для Telegram): отдельный сервис, домен вида `wp.<domain>`, выдача юзерам через бота. Может жить на одном из VPS или на отдельном дешёвом сервере. Кандидат: mtproto proxy / готовый web-proxy с уникальным ключом на юзера (как у референса - ключ в пути URL).

## 4. Инфраструктура и закупки

### 4.1 VPS

| Локация | Кандидаты | Ориентир цены |
|---|---|---|
| Эстония | netcup (ближ. DC), PQ hosting, Melbicom EE, aeza | 3-6 €/мес |
| Великобритания | Hetzner (UK), OVH UK, netcup | 4-6 €/мес |

Требования к каждому VPS:
- KVM-виртуализация (не OpenVZ/LXC - нужен свой стек для xray)
- Ubuntu 24.04 LTS / Debian 12
- Включённый трафик >= 20 TB/мес либо честный безлимит (при 1 ТБ на юзера и 30+ юзерах это критично)
- Возможность смены IP или дешёвый доп. IP (на случай блокировок РКН)

### 4.2 Домен

- Основной кандидат: **proliv.net** (свободен, проверено по RDAP). Покупка у зарубежного регистратора (porkbun/namecheap/Cloudflare) ~$11-13/год; nic.ru показывал 1913 ₽ - дороже.
- Fallback под бюджет 300 ₽: `proliv.xyz` / `proliv.site` (1-й год ~100-300 ₽, продление дороже); .ru/.рф не брать - домен VPN-сервиса в РФ-зоне может быть делегирован РКН, подписки юзеров сломаются разом.
- DNS: регистраторский DNS или Cloudflare (free) для удобного управления поддоменами.
- Поддомены: `panel.`, `sub.`, `cdn-ee.`, `cdn-uk.`, `wp.` (TG-прокси), `app.` (mini app) - A-записи на VPS / CNAME на YC CDN.
- Тариф в боте называть без слова VPN: "Proliv Network - Универсальный Network" (как у ranteis "Универсальный Network") - чище для эквайринга и рекламы.

### 4.3 Смета

| Статья | Разово | В месяц |
|---|---|---|
| VPS EE | - | ~400-600 ₽ |
| VPS UK | - | ~450-700 ₽ |
| VPS под панель (если отдельно) | - | ~300-500 ₽ |
| Домен | ~1000-1300 ₽/год | ~100 ₽ |

Точка окупаемости: ~10-15 активных подписок по 179 ₽.

## 5. Установка и настройка Remnawave

Источник истины: docs.rw (remnawave). Ниже - конспект шагов.

### 5.1 Подготовка VPS (на каждом)

- [ ] Создать не-root юзера, настроить SSH по ключам, отключить парольный вход
- [ ] `apt update && apt upgrade`
- [ ] UFW: разрешить 22 (или свой порт SSH), порты ноды (443/tcp и выбранные)
- [ ] Docker + docker compose plugin
- [ ] (Опционально) fail2ban, unattended-upgrades, BBR

### 5.2 Панель

- [ ] DNS: `panel.<domain>` -> IP сервера панели, `sub.<domain>` -> туда же
- [ ] `docker compose` remnawave panel (PostgreSQL, Redis, panel, subscription page) - по официальному compose из docs.rw
- [ ] Реверс-прокси (Caddy/nginx или встроенный) с HTTPS Let's Encrypt
- [ ] Создать админа, сменить дефолтные секреты, включить 2FA если есть
- [ ] Проверить выдачу subscription-ссылки тестовому юзеру

### 5.3 Ноды

- [ ] В панели создать ноду, получить ключ/секрет
- [ ] На VPS EE и UK поднять remnawave node контейнер с этим ключом
- [ ] Проверить статус ноды в панели (online)

### 5.4 Инбаунды и профили

- Основной транспорт: **VLESS + Reality** (не требует сертификатов на нодах, маскируется под чужой TLS - напр. dest `www.yahoo.com:443` или регионально правдоподобный SNI)
- Дополнительный транспорт под CDN: **VLESS + WebSocket + TLS** через `cdn-ee.<domain>` / `cdn-uk.<domain>` - с реальными сертификатами, терминация на CDN или на ноде (см. раздел 6)
- HWID-лимит: 5 устройств на юзера (включается в панели, работает с клиентами Happ/др. поддерживающими HWID)
- Лимит трафика: 1 ТБ с ежемесячным сбросом

## 6. Yandex Cloud CDN для VPN-трафика

Важно: YC CDN штатно кэширует статику; проксирование WebSocket/VPN-трафика - нестандартное применение. По данным от команды (Владислав, у него свой VPN на этой схеме) - CDN в YC сейчас бесплатный. Перед реализацией проверить актуальные лимиты бесплатного тарифа и:

- [ ] Поддерживает ли YC CDN проксирование WebSocket (Upgrade-заголовки) без буферизации/обрывов
- [ ] Тарификация по ГБ - прикинуть стоимость при N юзеров x трафик (см. смету)
- [ ] Ограничения по протоколам: CDN может работать только с HTTP(S) - тогда схема = VLESS+WS+TLS через CDN-домен

### Схема

1. CDN resource в YC: origin = `cdn-ee.<domain>` (A-запись на VPS EE)
2. Юзерский конфиг: connect to `cdn-ee.<domain>:443`, WS path `/ws`, TLS on; CDN форвардит на ноду
3. Аналогично UK

### Риски и план Б

- Если YC CDN рвёт WS / не пропускает - план Б: Cloudflare free plan делает это испытанно (grey cloud -> orange cloud), либо Reality напрямую без CDN
- Прямые IP нод всё равно оставить как фолбэк-конфиги в подписке

## 7. Telegram-бот

### 7.1 База

- Форк/основа: `remnawave-tg-shop` (опенсорс, заточен под remnawave API) - сокращает разработку до конфигурации

### 7.2 Функционал (по референсу ranteis)

- [ ] Старт: приветствие, ID юзера, баллы
- [ ] Карточка подписки: статус, тариф, дата окончания, трафик (X из 1000 ГБ), дата сброса
- [ ] Кнопка "Подключиться" - deeplink в клиентское приложение (Happ/v2rayNG/Streisand) с подпиской
- [ ] "Устройства" - список HWID-устройств, возможность сброса
- [ ] "Подписка" - покупка/продление, докупка трафика и устройств
- [ ] Реферальная система: ссылка, процент с оплат друга, скидка другу, обмен баллов на дни / вывод

- [ ] TG-прокси: кнопка "Подключить прокси" - веб-прокси для Telegram (как wp.ranteis.app у референса), бонус для юзеров помимо VPN

- Баннеры наверху карточек: лого + слоган, под каждый раздел свой

## 8. Mini App (личный кабинет)

Свой webapp под бренд, открывается из бота.

### Требования

- Авторизация: `initData` Telegram WebApp -> верификация подписи на бэкенде -> маппинг на юзера remnawave
- Экраны:
  - Главная: статус подписки, трафик (прогресс-бар), дни до конца
  - Подключение: кнопки под iOS/Android/Windows/macOS, QR-код, копирование ссылки
  - Устройства: список HWID, отвязка
  - Тарифы: покупка/продление/докупка
  - Рефералка: ссылка, статистика, вывод
- Бренд: название/лого в стиле ranteis (своё, не копировать)
- Стек (предложение): React/Vue + Telegram UI components, бэкенд = API бота или BFF к remnawave API
- Хостинг: статика за тем же доменом (`app.<domain>`) или `sub.<domain>`

### MVP vs полная версия

- MVP: штатная subscription page remnawave как mini app (быстро, 0 разработки)
- Полная: свой webapp - отдельный этап после запуска продаж

## 9. Безопасность и операционка

- [ ] Все админки за HTTPS + нестандартный путь/порт, IP allowlist на панель если возможно
- [ ] Секреты в .env, не в git; разные секреты на ноду/панель/бота
- [ ] Бэкапы: PostgreSQL панели (pg_dump по cron, off-site копия) - там юзеры и подписки
- [ ] Мониторинг: uptime-чек нод и CDN (uptime kuma на панельном VPS или внешний), алерты в TG
- [ ] Логи нод: без персональных данных, ротация
- [ ] План на блокировку IP: процедура смены IP VPS / пересоздания VPS без потери конфига (ноды stateless, конфиг в панели)

## 10. Юридика и риски

- Продажа VPN-доступа в РФ: регуляторный риск (РКН блокирует VPN-сервисы и их рекламу; штрафы за рекламу VPN). Минимум - не рекламироваться открыто в РФ-сегменте, подготовить оферту.
- Приём картой через ЮKassa - самозанятость/ИП обязательны.
- Документы в боте (ПД, оферта) - обязательны при приёме платежей и обработке ПД.
- Yandex Cloud: аккаунт РФ, тарификация по факту - следить за счётом при росте трафика.
